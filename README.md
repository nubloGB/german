# Niemiecki z Schritte Plus Neu B1

Strona do nauki niemieckiego na podstawie podręcznika **Schritte Plus Neu B1.1**. Każda lekcja to samodzielna aplikacja w przeglądarce: quizy gramatyczne i fiszki słownictwa. Nie trzeba nic instalować ani budować.

**Adres na żywo:** https://nublogb.github.io/german/

## Lekcje

- [Lektion 4 – Sprachen](https://nublogb.github.io/german/lektion4/) — quiz i fiszki słownictwa

## Jak dodać kolejną lekcję

1. Wgraj pliki lekcji do katalogu, np. `lektion5/index.html`.
2. Dopisz kartę w `index.html` (siatka `.grid`).
3. Wypchnij zmiany na gałąź `main`.

Publikacją zajmuje się GitHub Actions (`.github/workflows/pages.yml`).
